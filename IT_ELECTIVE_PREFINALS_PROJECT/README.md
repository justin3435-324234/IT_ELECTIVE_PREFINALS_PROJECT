# Help Desk Management System## OverviewASP.NET Core 8.0 MVC Application built using Entity Framework Core with SQLite (`lycevm.db`).
Designed for IT ELECTIVE 1 pre-finals project requirements.
## Architecture- **Framework**: ASP.NET Core 8.0 MVC- **Database**: SQLite (`lycevm.db`)- **ORM**: Entity Framework Core 8.0
## Features- Department, Employee, and Team Management- Customer and Ticket Management- Multi-employee Ticket Assignments- Ticket Internal Comments, Tags, and Attachments- Reporting Dashboard: Employee Workload, Unassigned Tickets, and Category Hierarchy
## Setup and Execution1. Verify `lycevm.db` exists in the project root directory.2. Run `dotnet restore`3. Run `dotnet run`
